# Guía didáctica para el informe y defensa (10 minutos + 5 preguntas)

## Guion sugerido, siempre sustentado con evidencias propias

1. Problema de negocio, reglas y alcance del sistema de venta de minerales y gemas.
2. MERE corregido: capturar imagen real y explicar diferencias de Fase 1 (pendiente de los archivos de Fase 1).
3. Modelo relacional final: abrir Workbench, explicar COLECCION, PIEZA y sus subtipos; VENTA + DETALLE_VENTA; CLIENTE; PERSONAL; EVALUACION; roles.
4. Poblamiento: ejecutar conteos, explicar Faker/datos sintéticos y validar FK, cantidad de piezas/compras y totales.
5. SQL avanzado: identificar R1...R12; ejecutar cada objeto en Workbench y guardar captura con código, sentencia ejecutada, salida e interpretación de 2–4 líneas.
6. PMV: iniciar sesión como gestor, registrar una venta; como catalogador, modificar una colección y pieza; como admin, mostrar todas las opciones; dashboard P1–P4.
7. Docker y despliegue: mostrar `docker compose ps`, la web en 8501 y el volumen persistente; distinguir Workbench (cliente) de MySQL (servidor).
8. Responsabilidad y uso de IA: explicar aportes concretos, errores corregidos, validaciones y conclusiones individuales.
